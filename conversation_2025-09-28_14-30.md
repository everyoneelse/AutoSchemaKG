## 语言设置的位置和机制

在 `1_slice_kg_extraction.py` 文件中，**语言设置不是直接在代码中配置的**，而是通过以下机制工作的：

### 1. 数据文件中的语言标识
语言是在输入的数据文件中通过 `metadata.lang` 字段设置的，例如：
```json
{
    "id": 1,
    "text": "你的文本内容",
    "metadata": {
        "lang": "zh-CN"  // 这里设置语言
    }
}
```

### 2. 支持的语言
根据 `TRIPLE_INSTRUCTIONS` 定义，目前支持三种语言：
- `"en"` - 英文
- `"zh-CN"` - 简体中文  
- `"zh-HK"` - 繁体中文

### 3. 语言处理逻辑
在 `/workspace/atlas_rag/kg_construction/triple_extraction.py` 文件中：

```python
# 第70-75行：语言过滤函数
def filter_language_content(self, sample: Dict[str, Any]) -> bool:
    metadata = sample.get("metadata", {})
    language = metadata.get("lang", "en")  # 默认英文
    supported_languages = list(TRIPLE_INSTRUCTIONS.keys())
    return language in supported_languages

# 第176-181行：根据语言选择提示词
language = item.get("metadata",{}).get("lang", "en")

```

### 4. 如何设置语言
要设置语言，你需要：
1. 在输入的JSON数据文件中，为每个条目的 `metadata` 字段添加 `"lang"` 属性
2. 将 `"lang"` 设置为 `"en"`、`"zh-CN"` 或 `"zh-HK"` 之一

例如，如果你要处理中文数据，确保你的数据文件格式如下：
```json
[
    {
        "id": 1,
        "text": "你的中文文本内容",
        "metadata": {
            "lang": "zh-CN"
        }
    }
]
```

这样系统就会自动使用对应语言的提示词模板进行知识图谱提取。
